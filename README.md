### About this project
This is a computer vision based football player analysis project which can help to track and analyse players performance after the football match

### Packages used
- pytorch
- ultralytics
- torchvision
- rfdetr
- cv2

### Deeplearning/Computervision modules
- `RFdetrMedium` for object detection.
- `YOLO` for player tracking
- `resnet50` for extracting the jersey number of the player.

### What this project does?
I tried to implement some features like
1. Player tracking
2. Jersey number identification
3. Goal detection
4. Team classification
5. And ball control for each team
